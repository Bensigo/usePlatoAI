## Milestone 009 Requires Native Desktop Evidence

- kind: lesson
- source: https://github.com/Bensigo/usePlatoAI/issues/258 and docs/visual-evidence/milestone-009-checklist.md
- confidence: verified
- created_at: 2026-05-24

For Milestone 009 desktop companion work, browser-localhost screenshots do not prove product behavior. Reviews should require evidence from the real Tauri desktop window, using Computer Use or equivalent desktop inspection to verify window placement, always-on-top behavior, interactions, persisted position, and hidden avatar states.
